# Code of Conduct

MeantByMe contributors are expected to make collaboration safe, respectful, and
accessible—especially when discussing disability, communication, patient
agency, caregiving, personal data, and voice identity.

## Expected behavior

- Respect each person's stated identity, communication method, pace, and
  boundaries.
- Critique code and ideas without attacking people.
- Use inclusive language and make space for alternative input methods.
- Treat patient stories, recordings, profiles, and health-related information
  as sensitive.
- State uncertainty, limitations, conflicts of interest, and the difference
  between simulation and real-world evidence.
- Stop sharing or using material when consent or rights are unclear.

## Unacceptable behavior

- Harassment, discrimination, intimidation, sexualized conduct, or personal
  attacks.
- Publishing private information, credentials, patient data, voice samples, or
  vulnerability details without authorization.
- Impersonating a patient, caregiver, contributor, or maintainer.
- Presenting unconfirmed AI output as a person's own speech.
- Making unsupported medical, clinical, accessibility, or performance claims.

## Reporting

Report conduct concerns privately to a repository maintainer. Security,
privacy, consent-boundary, or personal-voice issues should follow
[SECURITY.md](SECURITY.md). Maintainers may remove content, restrict
participation, or take other proportionate action to protect contributors and
users.

This code applies in repository spaces and in public representation of the
project.
